# Potion Duration Bars

A RuneLite Plugin Hub plugin that displays active potion effects as countdown bars. Bars appear only while an effect is active. Move the overlay with RuneLite's Alt-drag controls and use the plugin setting to lock or unlock its position.

## Tracked effects

The first version uses duration variables exposed by RuneLite for divine combat, ranging, magic, bastion, and battlemage potions; stamina; antifire and super antifire; overload; prayer enhance; goading; prayer regeneration; surge; and moonlight potions. Potion coverage depends on the timer data available from the client.

## Development

This is a standard RuneLite external plugin Gradle project. Open the folder in IntelliJ IDEA and run the project using the RuneLite plugin development instructions. Plugin Hub publication requires a public source repository and a separate submission to the RuneLite Plugin Hub.
